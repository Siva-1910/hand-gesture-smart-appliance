# Hand Gesture Controlled Smart Appliance System 🖐️

A touchless appliance control system using MediaPipe hand-landmark 
tracking and custom gesture classifiers.

## Features
- Touchless control of smart appliances using hand gestures
- Works across varied lighting conditions
- Real-time inference with sub-100ms latency
- Custom gesture classifiers for reliable detection

## Tech Stack
- Python
- MediaPipe
- OpenCV
- IoT

## Results
- 95%+ gesture recognition accuracy
- False-positive activations under 3%
- Sub-100ms latency for responsive experience
